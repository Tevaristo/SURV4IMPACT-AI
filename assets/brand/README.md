# Identidade institucional

Estes ativos são apresentados sem recomposição das marcas e sobre fundo branco.

- `ipps-iscte.png` — versão principal com descrição, obtida na página oficial de identidade do IPPS-Iscte: https://ipps.iscte-iul.pt/pt/ipps/identidade-e-imagem
- `adc.png` — versão horizontal para fundo branco, extraída do pacote oficial `LogoADC.zip`: https://www.adcoesao.pt/quem-somos/logotipo-e-manual-de-normas/
- `pat2030-portugal2030-ue.png` — barra oficial PAT 2030 + Portugal 2030 + «Cofinanciado pela União Europeia»: https://www.adcoesao.pt/wp-content/uploads/PAT2030_BarraCofinan_Designacao_RGB_2925px.png

Na interface, IPPS-Iscte e AD&C formam um grupo institucional separado da barra de programa e cofinanciamento. A ordem interna da barra PAT 2030 → Portugal 2030 → União Europeia não deve ser alterada.
